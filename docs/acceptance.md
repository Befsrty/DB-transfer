# Протокол приёмочных испытаний

Программа испытаний — [tz-prototype.md](tz-prototype.md), раздел 6.2: там порядок проверки и ожидаемый результат по каждому пункту. Здесь — отметки о прохождении.

Условия: чистый клон репозитория, Docker запущен, демо-набор из репозитория.

| № | Проверка | Как проверить быстрее всего | Результат | Отметка |
|---|---|---|---|---|
| ПИ-1 | Установка | Команды из README, раздел «Запуск»; затем `uv run dbtransfer run-demo` | | |
| ПИ-2 | Импорт | Вкладка «Импорт» или `dbtransfer import`; сравнить с `demo/bw_export/EXPECTED.md` | | |
| ПИ-3 | Ошибочные выгрузки | Копия `demo/bw_export` с удалённой колонкой в `RSDIOBJ.csv` и испорченной строкой в `RSTRAN.csv`; импорт этой папки | | |
| ПИ-4 | Отчёт о сложности | Вкладка «Сложность» → «Сформировать Excel» или `dbtransfer report` | | |

| ПИ-8 | Загрузка и прогон | Вкладка «Развёртывание»: справочники, загрузка 1, «Прогон»; загрузка 2, «Прогон»; журнал изменений `dbt_dwh.zsd_a01_changelog` | | |
