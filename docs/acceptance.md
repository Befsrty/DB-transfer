## Замечания

| № | Что не так | Что сделано | Статус |
|---|---|---|---|
| 1 | Пустое поле признака (например, MATERIAL) загружается пустой строкой, а не NULL; пустой показатель — NULL | Так и задумано: признаки в BW не бывают NULL, пустое значение — это «не задано» | не требует правки |
| 2 | В ZSD_A02 есть строка с `calmonth = 000000` из строк с датой `00000000` | Совпадает с эталоном: так ведёт себя BW (начальное значение времени) | не требует правки |
| 3 | В Git Bash без `PYTHONUTF8=1` справка CLI выводится нечитаемо | В PowerShell, cmd и интерфейсе всё в порядке; в README рекомендуется PowerShell | не требует правки |
